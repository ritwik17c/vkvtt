🗓 Import Approved Leave / OD / Special from Excel

For approved school records. You may upload either the app’s clean import template or the existing VKV leave-statement workbook (for example Leave_record_2026-27.xlsx). Past, present and future approved records within Session 2026–27 can be imported. The app first previews and validates every record; nothing is saved until you confirm.

Template format: preferred sheet name Past_Leave_History. Existing VKV leave-statement format: month blocks with FROM / TO / VL / EL / CL / SEL / EOL / Maternity Leave are detected automatically. Teacher Code is matched first; legacy teacher names are matched carefully against the master roster.
